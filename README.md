# Titanic Survival Prediction

A beginner machine learning project that predicts whether a passenger survived the Titanic disaster using passenger data.

## Features Used
- Passenger class
- Sex
- Age
- Fare

## Technologies Used
- Python
- pandas
- seaborn
- scikit-learn
- matplotlib

## Concepts Used
- Logistic Regression
- Data Cleaning
- Missing Value Handling
- Feature Encoding
- Classification

## Purpose
Built to practice real-world machine learning workflow including preprocessing and prediction.
